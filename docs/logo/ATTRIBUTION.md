# Logo attribution

The current PodDock logo (dot-docking-into-tray mark, tile variants, and all
app icons) is entirely original geometry created for this project — no
third-party SVG assets are used.

An earlier iteration derived its pod shape from Fluent UI Emoji (MIT); that
design has since been fully replaced, and no Fluent-derived paths remain in
any current file.

All logo assets follow the repository license (`LICENSE` at the repository
root).
